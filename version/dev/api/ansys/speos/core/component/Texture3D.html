Texture3D#

class ansys.speos.core.component.Texture3D(project, name, description='', metadata=None, default_parameters=None, texture_3d_instance=None)#

Represent the Speos 3D texture feature.

A 3D texture repeats a pattern body on a support body of the project geometry, following a 3D mapping file.

Parameters:
projectansys.speos.core.project.Project

Project that will own the feature.

namestr

Name of the feature.

descriptionstr, optional

Description of the feature. By default, "".

metadataOptional[Mapping[str, str]], optional

Metadata of the feature. By default, {}.

default_parametersOptional[ansys.speos.core.generic.parameters.Texture3DParameters], optional

Allows to provide parameters to overwrite the default parameters. By default, None, which uses Texture3DParameters defaults.

texture_3d_instanceOptional[ansys.speos.core.kernel.scene.ProtoScene.Texture3D], optional

3D texture protobuf message retrieved from an existing scene. By default, None, which creates a new 3D texture.

Parameters:

  • project (Texture3D.__init__.project)

  • name (str)

  • description (str)

  • metadata (Optional[Mapping[str, str]])

  • default_parameters (Optional[ansys.speos.core.generic.parameters.Texture3DParameters])

  • texture_3d_instance (Optional[ansys.speos.core.kernel.ProtoScene.Texture3D])

Notes

The 3D texture feature requires a Speos server of version 2027 R1 or higher. The pattern body must not be a body of the scene root part taken in the simulation.

Texture3D.create_pattern_material(name, description='', metadata=None, parameters=None)#

Create a new optical property applied on the 3D texture pattern body.

The created optical property belongs to the 3D texture pattern: it is not registered as a project feature.

Parameters:
namestr

descriptionstr, optional

Description of the optical property. By default, "".

metadataOptional[Mapping[str, str]], optional

Allows to provide parameters to overwrite default parameters.

Optical property applied on the pattern body.

Notes

Call ansys.speos.core.opt_prop.OptProp.delete() on the returned object to remove it from the 3D texture pattern, then commit the 3D texture.
