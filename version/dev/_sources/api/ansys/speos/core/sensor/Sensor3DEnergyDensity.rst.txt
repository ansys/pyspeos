.. py:class:: ansys.speos.core.sensor.Sensor3DEnergyDensity(project, name, description = '', metadata = None, sensor_instance = None, default_parameters = None)

   Bases: :py:obj:`BaseSensor`


   
   Sensor feature: volumetric 3D energy density.


   :Parameters:

       **project** : :obj:`ansys.speos.core.project.Project`
           Project that owns the feature.

       **name** : :class:`python:str`
           Name of the feature.

       **description** : :class:`python:str`, :obj:`optional`
           Description of the feature.

       **metadata** : :obj:`Mapping`\[:class:`python:str`, :class:`python:str`], :obj:`optional`
           User metadata.

       **sensor_instance** : :obj:`ProtoScene.SensorInstance`, :obj:`optional`
           Existing instance to load instead of creating a new sensor.

       **default_parameters** : :obj:`EnergyDensity3DSensorParameters`, :obj:`optional`
           Parameters to apply. When loading, ``None`` preserves existing values.











   .. rubric:: Notes

   Requires Speos 2027 R1 SP0 and sensor template v2. The default photometric
   volume is a 50 mm cube centered on its axis-system origin, sampled with
   100 voxels along each edge, with no layer separation.
   Result-file readers and VTP export are not provided for this sensor.
   Light Expert (LXP) is not supported.
