





:class:`ScatteringSurfaceFile`
==============================


.. py:class:: ansys.speos.core.input_files.scattering_surface.ScatteringSurfaceFile(wavelengths = _DEFAULT_WAVELENGTHS, incident_angles = _DEFAULT_INCIDENT_ANGLES, samples = None, description = _DEFAULT_DESCRIPTION)

   Bases: :py:obj:`ansys.speos.core.input_files._base.SpeosTextFileFormat`


   
   Speos ``*.scattering`` file, a scattering surface varying with angle and wavelength.

   The file holds one
   :class:`ansys.speos.core.input_files.scattering_surface.ScatteringSurfaceSample` per
   angle of incidence and per wavelength, stored in
   ``samples[incidence_index][wavelength_index]``.

   :Parameters:

       **wavelengths** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Wavelengths of the samples, in nm, sorted in increasing order. At least two
           wavelengths are required. By default, ``[400.0, 550.0, 700.0]``.

       **incident_angles** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Angles of incidence of the samples, in degrees, sorted in increasing order.
           ``0`` and ``90`` are required. By default, ``[0.0, 60.0, 90.0]``.

       **samples** : :obj:`List`\[:obj:`List`\[:obj:`ScatteringSurfaceSample`]], :obj:`optional`
           Contributions, one row per angle of incidence and one column per wavelength.
           By default, a 3 x 3 grid of independent default
           :class:`ansys.speos.core.input_files.scattering_surface.ScatteringSurfaceSample`
           objects, which specularly reflect all the light.

       **description** : :class:`python:str`, :obj:`optional`
           Free text written on the second line of the file. By default,
           ``"Scattering surface"``.











   .. rubric:: Notes

   Called without arguments, the constructor creates a 3 x 3 grid of perfect specular
   reflectors. Pass ``wavelengths``, ``incident_angles`` and ``samples`` together to
   describe another grid, since each default only matches the other ones.

   Empty lists allow staged construction, but :meth:`ScatteringSurfaceFile.validate` and
   ``save()`` require a complete surface. Nonempty assignments are checked against the
   configured axes and grid. To resize a populated grid, clear
   :attr:`ScatteringSurfaceFile.samples`, assign the new axes,
   then assign the new grid. List getters return copies of the containers, while sample
   objects remain shared so their validated properties can be edited directly.


   .. rubric:: Examples

   >>> from ansys.speos.core.input_files.scattering_surface import (
   ...     ScatteringSurfaceFile,
   ...     ScatteringSurfaceSample,
   ... )
   >>> grey = ScatteringSurfaceSample(specular_reflection=0.0, lambertian_reflection=50.0)
   >>> surface = ScatteringSurfaceFile(
   ...     wavelengths=[400.0, 700.0],
   ...     incident_angles=[0.0, 90.0],
   ...     samples=[[grey, grey], [grey, grey]],
   ... )
   >>> surface.save("grey.scattering")

Method detail
-------------

.. py:method:: validate()

   
   Check the surface against the constraints of the ``*.scattering`` format.









   :Raises:

       :obj:`ValueError`
           If fewer than two wavelengths are given, the angles of incidence do not span
           0 to 90 degrees, the sample grid does not match the wavelengths and angles, or
           a sample holds invalid contributions.
