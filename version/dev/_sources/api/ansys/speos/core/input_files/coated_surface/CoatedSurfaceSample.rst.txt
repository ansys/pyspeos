





:class:`CoatedSurfaceSample`
============================


.. py:class:: ansys.speos.core.input_files.coated_surface.CoatedSurfaceSample(reflection_p = 100.0, transmission_p = 0.0, reflection_s = 100.0, transmission_s = 0.0)

   Bases: :py:obj:`ansys.speos.core.input_files._base._ValueComparable`


   
   Coating response at one angle of incidence and one wavelength.

   Called without arguments, the constructor creates a perfect reflector.

   :Parameters:

       **reflection_p** : :class:`python:float`, :obj:`optional`
           Reflected part of the P polarization, in percent. By default, ``100.0``.

       **transmission_p** : :class:`python:float`, :obj:`optional`
           Transmitted part of the P polarization, in percent. By default, ``0.0``.

       **reflection_s** : :class:`python:float`, :obj:`optional`
           Reflected part of the S polarization, in percent. By default, ``100.0``.

       **transmission_s** : :class:`python:float`, :obj:`optional`
           Transmitted part of the S polarization, in percent. By default, ``0.0``.

Method detail
-------------

.. py:method:: validate()

   
   Check the coating response of the sample.









   :Raises:

       :obj:`ValueError`
           If a value is outside the 0 to 100 range.

   :Warns:

       :obj:`UserWarning`
           If computed absorption is negative, excluding rounding noise within 1e-9 percent.



   .. rubric:: Notes

   A negative :attr:`CoatedSurfaceSample.absorption_p` or
   :attr:`CoatedSurfaceSample.absorption_s` is not rejected: the
   coating samples published by Ansys do overrun 100 percent on a polarization, and
   the Coated Surface Editor only flags it.
