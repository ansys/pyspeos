





:class:`MaterialMetallicCurve`
==============================


.. py:class:: ansys.speos.core.input_files.material.MaterialMetallicCurve(wavelengths = _DEFAULT_WAVELENGTHS, indices = _DEFAULT_METALLIC_INDICES, extinctions = _DEFAULT_METALLIC_EXTINCTIONS)

   Bases: :py:obj:`ansys.speos.core.input_files._base._ValueComparable`


   
   Dispersion of a metal given by its complex refractive index.


   :Parameters:

       **wavelengths** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Wavelengths of the curve, in nm. By default, ``[486.0, 532.0, 643.0]``.

       **indices** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Real part n of the refractive index at each wavelength. By default,
           ``[1.0, 1.0, 1.0]``.

       **extinctions** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Extinction coefficient k at each wavelength. By default, ``[0.0, 0.0, 0.0]``.











   .. rubric:: Notes

   The default refractive index and extinction values are placeholders, not the optical
   constants of a real metal.
