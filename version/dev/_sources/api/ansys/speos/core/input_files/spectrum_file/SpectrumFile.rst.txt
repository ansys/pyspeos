





:class:`SpectrumFile`
=====================


.. py:class:: ansys.speos.core.input_files.spectrum_file.SpectrumFile(wavelengths = _DEFAULT_WAVELENGTHS, values = _DEFAULT_VALUES, description = _DEFAULT_DESCRIPTION, *, percent = True)

   Bases: :py:obj:`ansys.speos.core.input_files._base.SpeosTextFileFormat`


   
   Speos ``*.spectrum`` file, holding a sampled spectral distribution.

   The file is the text (``v1``) flavor of the format: a header line, a description, the
   number of samples, then one ``wavelength<TAB>value`` line per sample. Files are read
   and written locally, no Speos server is needed.

   :Parameters:

       **wavelengths** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Wavelengths of the samples, in nm. By default, 11 wavelengths from 360 nm to 830 nm
           in 47 nm steps.

       **values** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Relative spectral values of the samples, in percent (0 to 100). By default, the
           values of the default 5200 K blackbody spectrum, normalized to 100 at its sampled
           maximum.

       **description** : :class:`python:str`, :obj:`optional`
           Free text written on the second line of the file. By default,
           ``"Blackbody at 5200.0 K"``.

       **percent** : :ref:`bool <python:bltin-boolean-values>`, :obj:`optional`
           Whether values are percentages limited to 0 to 100. By default, ``True``. Set it to
           ``False`` for spectra in other units, such as the absorption and excitance spectra
           of a fluorescent dye in mm-1, whose values only need to be finite.











   .. rubric:: Notes

   Called without arguments, the constructor creates the default 5200 K blackbody
   spectrum. Pass ``wavelengths`` and ``values`` together to describe another spectrum.

   :attr:`SpectrumFile.percent` is a validation setting: it is not written to the file,
   and a loaded ``*.spectrum`` file has it set to ``True``.

   Construction and setters validate numeric data before storing it. List getters return
   copies; assign an edited list back to change the model. Empty columns permit staged
   construction, while :meth:`SpectrumFile.validate` and ``save()`` require complete
   matching columns. To resize a populated spectrum, clear :attr:`SpectrumFile.values`,
   replace :attr:`SpectrumFile.wavelengths`, then
   assign the new values.


   .. rubric:: Examples

   >>> from ansys.speos.core.input_files.spectrum_file import SpectrumFile
   >>> SpectrumFile(wavelengths=[400.0, 700.0], values=[100.0, 50.0]).save("led.spectrum")

.. py:method:: validate()

   
   Check the spectrum against the constraints of the ``*.spectrum`` format.









   :Raises:

       :obj:`ValueError`
           If the sample lists are empty, do not have the same length, hold more than
           32767 samples, or if :attr:`SpectrumFile.percent` is ``True`` and a value is
           outside the 0 to 100 percent range.
