





:class:`SimpleScatteringSurfaceFile`
====================================


.. py:class:: ansys.speos.core.input_files.simple_scattering_surface.SimpleScatteringSurfaceFile(mode = SimpleScatteringMode.reflection, absorption = 10.0, lambertian = 10.0, gaussian = 80.0, gaussian_fwhm = 25.0, lambertian_transmission = 0.0, gaussian_transmission = 0.0, gaussian_fwhm_transmission = 0.0, reflection = None, description = 'Scattering surface')

   Bases: :py:obj:`ansys.speos.core.input_files._base.SpeosTextFileFormat`


   
   Speos ``*.simplescattering`` file, a scattering surface with no spectral dependency.

   The incident light is split into an absorbed part and, on each active side of the
   surface, a Lambertian, a Gaussian and a specular part. The specular part is the
   complement to 100 percent of the Lambertian and Gaussian ones.

   :Parameters:

       **mode** : :obj:`SimpleScatteringMode`, :obj:`optional`
           Sides of the surface that scatter light. By default,
           ``SimpleScatteringMode.reflection``.

       **absorption** : :class:`python:float`, :obj:`optional`
           Absorbed part of the incident light, in percent. By default, ``10.0``.

       **lambertian** : :class:`python:float`, :obj:`optional`
           Lambertian part in percent. In ``"Both"`` mode this is the reflection side.
           By default, ``10.0``.

       **gaussian** : :class:`python:float`, :obj:`optional`
           Gaussian part in percent. In ``"Both"`` mode this is the reflection side.
           By default, ``80.0``.

       **gaussian_fwhm** : :class:`python:float`, :obj:`optional`
           Full width at half maximum of the Gaussian lobe, in degrees. In ``"Both"`` mode
           this is the reflection side. By default, ``25.0``.

       **lambertian_transmission** : :class:`python:float`, :obj:`optional`
           Lambertian part of the transmission side, in percent. ``"Both"`` mode only.
           By default, ``0.0``.

       **gaussian_transmission** : :class:`python:float`, :obj:`optional`
           Gaussian part of the transmission side, in percent. ``"Both"`` mode only.
           By default, ``0.0``.

       **gaussian_fwhm_transmission** : :class:`python:float`, :obj:`optional`
           Full width at half maximum of the transmission Gaussian lobe, in degrees.
           ``"Both"`` mode only. By default, ``0.0``.

       **reflection** : :obj:`Optional`\[:class:`python:float`], :obj:`optional`
           Reflected part in percent, the transmitted part being its complement to 100.
           ``"Both"`` mode only. By default, ``None``, which makes the split follow the
           Fresnel laws.

       **description** : :class:`python:str`, :obj:`optional`
           Free text written on the second line of the file. By default,
           ``"Scattering surface"``.











   .. rubric:: Notes

   Called without arguments, the constructor creates a surface with absorption 10%,
   Lambertian reflection 10%, and Gaussian reflection 80%. These contributions fill the
   side budget.

   Setters reject invalid values before changing the model. Lower an outgoing contribution
   before increasing another in a fully allocated side budget. Transmission-side values
   remain stored outside Both mode; enabling Both validates their combined budget.


   .. rubric:: Examples

   >>> from ansys.speos.core.input_files.simple_scattering_surface import (
   ...     SimpleScatteringMode,
   ...     SimpleScatteringSurfaceFile,
   ... )
   >>> diffuser = SimpleScatteringSurfaceFile(
   ...     mode=SimpleScatteringMode.reflection, lambertian=100.0, gaussian=0.0
   ... )
   >>> diffuser.save("white_diffuser.simplescattering")
