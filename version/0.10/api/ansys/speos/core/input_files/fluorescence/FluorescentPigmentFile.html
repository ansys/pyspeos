FluorescentPigmentFile#

class ansys.speos.core.input_files.fluorescence.FluorescentPigmentFile(description='Fluorescent pigment', absorption_spectrum=None, efficiency_spectrum=None, excitance_spectrum=None, emission_spectrum=None, measured_concentration=1.0, spectrum_selection_code=0)#

Bases: ansys.speos.core.input_files._base.SpeosTextFileFormat

Speos *.dye pigment, with sampled absorption and emission spectra.

The default spectra and settings match the default entry in the Speos dye editor. The model supports the editor’s default unscattering pigment with isotropic emission. Other scattering and emission-distribution models are not yet represented. Changing a spectrum does not recalculate the other spectra; keep derived data consistent.

Each spectrum is a ansys.speos.core.input_files.spectrum_file.SpectrumFile, so an existing *.spectrum file can be loaded and assigned directly. Assigning a spectrum sets its SpectrumFile.percent attribute to match its role: False for the absorption and excitance spectra, in mm-1, whose values may exceed 100, and True for the efficiency and emission spectra, in percent.

Excitance spectrum, in mm-1. Values may exceed 100.

Emission spectrum, in percent.

Concentration at which the dye was measured. Defaults to 1.0.

spectrum_selection_codeint, optional

Spectrum selection code stored by the dye editor: 0, 1, or 2. Defaults to 0.
