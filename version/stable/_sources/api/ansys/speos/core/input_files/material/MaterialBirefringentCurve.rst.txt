





:class:`MaterialBirefringentCurve`
==================================


.. py:class:: ansys.speos.core.input_files.material.MaterialBirefringentCurve(wavelength = 550.0, index_a = 1.5, index_b = 1.51, index_c = 1.65, optical_class = MaterialOpticalClass.negative_uniaxial)

   Bases: :py:obj:`ansys.speos.core.input_files._base._ValueComparable`


   
   Refractive indices of a birefringent material along its three axes.

   Speos does not make the indices of a birefringent material vary with the wavelength
   when they are given explicitly, so a single index per axis is stored.

   :Parameters:

       **wavelength** : :class:`python:float`, :obj:`optional`
           Wavelength the indices are given at, in nm. By default, ``550.0``.

       **index_a** : :class:`python:float`, :obj:`optional`
           Refractive index along the ``a`` axis. By default, ``1.5``.

       **index_b** : :class:`python:float`, :obj:`optional`
           Refractive index along the ``b`` axis. By default, ``1.51``.

       **index_c** : :class:`python:float`, :obj:`optional`
           Refractive index along the ``c`` axis. By default, ``1.65``.

       **optical_class** : :obj:`MaterialOpticalClass`, :obj:`optional`
           Optical class. By default, ``MaterialOpticalClass.negative_uniaxial``.
