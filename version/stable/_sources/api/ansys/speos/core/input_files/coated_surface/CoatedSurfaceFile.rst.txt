





:class:`CoatedSurfaceFile`
==========================


.. py:class:: ansys.speos.core.input_files.coated_surface.CoatedSurfaceFile(wavelengths = _DEFAULT_WAVELENGTHS, incident_angles = _DEFAULT_INCIDENT_ANGLES, samples = None, description = _DEFAULT_DESCRIPTION)

   Bases: :py:obj:`ansys.speos.core.input_files._base.SpeosTextFileFormat`


   
   Speos ``*.coated`` file, a non-scattering coating varying with angle and wavelength.

   The file holds one
   :class:`ansys.speos.core.input_files.coated_surface.CoatedSurfaceSample` per angle of
   incidence and per wavelength, stored in ``samples[incidence_index][wavelength_index]``.

   :Parameters:

       **wavelengths** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Wavelengths of the samples, in nm, sorted in increasing order. By default,
           ``[400.0, 550.0, 700.0]``.

       **incident_angles** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Angles of incidence of the samples, in degrees, sorted in increasing order.
           By default, ``[0.0, 60.0, 90.0]``.

       **samples** : :obj:`List`\[:obj:`List`\[:obj:`CoatedSurfaceSample`]], :obj:`optional`
           Coating responses, one row per angle of incidence and one column per wavelength.
           By default, a 3 x 3 grid of independent default
           :class:`ansys.speos.core.input_files.coated_surface.CoatedSurfaceSample` objects,
           which reflect all the light.

       **description** : :class:`python:str`, :obj:`optional`
           Free text written on the second line of the file. By default, ``"Coating surface"``.











   .. rubric:: Notes

   Called without arguments, the constructor creates a 3 x 3 grid of perfect reflectors.
   Pass ``wavelengths``, ``incident_angles`` and ``samples`` together to describe another
   grid, since each default only matches the other ones.

   A Speos coating is only valid for the rays crossing the interface in one direction.
   List getters copy the containers, while sample objects remain shared and editable
   through validated properties. To resize a populated grid, clear
   :attr:`CoatedSurfaceFile.samples`, set the axes, then assign the new grid. Empty lists
   allow drafts; ``save()`` requires complete axes and samples.


   .. rubric:: Examples

   >>> from ansys.speos.core.input_files.coated_surface import (
   ...     CoatedSurfaceFile,
   ...     CoatedSurfaceSample,
   ... )
   >>> sample = CoatedSurfaceSample(31.9, 68.1, 31.9, 68.1)
   >>> CoatedSurfaceFile(
   ...     wavelengths=[480.0, 780.0],
   ...     incident_angles=[0.0, 90.0],
   ...     samples=[[sample, sample], [sample, sample]],
   ... ).save("mirror.coated")
