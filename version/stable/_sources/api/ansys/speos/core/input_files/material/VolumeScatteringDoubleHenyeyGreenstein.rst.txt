





:class:`VolumeScatteringDoubleHenyeyGreenstein`
===============================================


.. py:class:: ansys.speos.core.input_files.material.VolumeScatteringDoubleHenyeyGreenstein(wavelengths = (), anisotropies_1 = _DEFAULT_ANISOTROPIES, anisotropies_2 = _DEFAULT_ANISOTROPIES, ratios = _DEFAULT_RATIOS)

   Bases: :py:obj:`ansys.speos.core.input_files._base._ValueComparable`


   
   Double Henyey-Greenstein scattering phase function.


   :Parameters:

       **wavelengths** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Wavelengths the factors are given at, in nm. A single wavelength means that the
           phase function does not depend on the wavelength. By default, ``[]``.

       **anisotropies_1** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           First anisotropy factor at each wavelength, between -1 and 1. By default,
           ``[0.9]``.

       **anisotropies_2** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Second anisotropy factor at each wavelength, between -1 and 1. By default,
           ``[0.9]``.

       **ratios** : :obj:`Sequence`\[:class:`python:float`], :obj:`optional`
           Weight between the first and the second anisotropy factor, at each wavelength.
           Values must be between 0 and 1. By default, ``[0.5]``.
