





:class:`ScatteringSurfaceSample`
================================


.. py:class:: ansys.speos.core.input_files.scattering_surface.ScatteringSurfaceSample(specular_reflection = 100.0, specular_transmission = 0.0, lambertian_reflection = 0.0, lambertian_transmission = 0.0, gaussian_reflection = 0.0, gaussian_transmission = 0.0, gaussian_fwhm_incidence_reflection = 0.0, gaussian_fwhm_incidence_transmission = 0.0, gaussian_fwhm_perpendicular_reflection = 0.0, gaussian_fwhm_perpendicular_transmission = 0.0)

   Bases: :py:obj:`ansys.speos.core.input_files._base._ValueComparable`


   
   Scattering contributions of a surface at one angle of incidence and one wavelength.

   Every contribution is a percentage of the incident light. What is left once the six
   contributions are summed is absorbed, see :attr:`ScatteringSurfaceSample.absorption`.
   Called without arguments, the constructor gives the sample of a new file in the Speos
   default scattering surface: a perfect specular reflector.

   :Parameters:

       **specular_reflection** : :class:`python:float`, :obj:`optional`
           Specularly reflected part, in percent. By default, ``100.0``.

       **specular_transmission** : :class:`python:float`, :obj:`optional`
           Specularly transmitted part, in percent. By default, ``0.0``.

       **lambertian_reflection** : :class:`python:float`, :obj:`optional`
           Lambertian reflected part, in percent. By default, ``0.0``.

       **lambertian_transmission** : :class:`python:float`, :obj:`optional`
           Lambertian transmitted part, in percent. By default, ``0.0``.

       **gaussian_reflection** : :class:`python:float`, :obj:`optional`
           Gaussian reflected part, in percent. By default, ``0.0``.

       **gaussian_transmission** : :class:`python:float`, :obj:`optional`
           Gaussian transmitted part, in percent. By default, ``0.0``.

       **gaussian_fwhm_incidence_reflection** : :class:`python:float`, :obj:`optional`
           Full width at half maximum of the reflected Gaussian lobe in the incidence plane,
           in degrees. By default, ``0.0``.

       **gaussian_fwhm_incidence_transmission** : :class:`python:float`, :obj:`optional`
           Full width at half maximum of the transmitted Gaussian lobe in the incidence
           plane, in degrees. By default, ``0.0``.

       **gaussian_fwhm_perpendicular_reflection** : :class:`python:float`, :obj:`optional`
           Full width at half maximum of the reflected Gaussian lobe in the perpendicular
           plane, in degrees. By default, ``0.0``.

       **gaussian_fwhm_perpendicular_transmission** : :class:`python:float`, :obj:`optional`
           Full width at half maximum of the transmitted Gaussian lobe in the perpendicular
           plane, in degrees. By default, ``0.0``.







   :Raises:

       :obj:`ValueError`
           If a percentage is outside 0 to 100 or a Gaussian width is outside 0 to 90 degrees.

   :Warns:

       :obj:`UserWarning`
           If computed absorption is negative, excluding rounding noise within 1e-9 percent.



   .. rubric:: Notes

   Construction and property assignments validate before storing a value. Negative
   absorption from measurement or rounding errors is preserved with a warning. Set
   ``specular_reflection`` explicitly when giving other contributions, since its default
   already reflects all the light.
